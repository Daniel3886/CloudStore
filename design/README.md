# Design

Working material behind the design refresh. Nothing here ships with the app.

- `landing.html`: the standalone landing page mockup built and reviewed with [Impeccable](https://impeccable.style). The real page lives in `frontend/features/landing/`.
- `screenshots/before/`: the app before this change, with sample data.
- `screenshots/after/`: the same screens after it.

The product facts the design relies on are in `../PRODUCT.md`, and the visual system (colours, type, components and rules) is in `../DESIGN.md`. `.impeccable/surfaces/` holds the landing page's design brief.
