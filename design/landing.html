Upload and sort into folders

Drag files in, make folders, rename and download. Folders are stored as key prefixes in S3, so the bucket stays readable outside the app too.

How it's built

A Spring Boot API and a Next.js app, in one repository you can read end to end.

Spring Boot API
Files, sharing, public links and the activity log, grouped by feature.backend/…/file/service/
JWT sign-in
Short-lived access tokens with refresh tokens; accounts verified by an emailed code.backend/…/auth/filter/JwtFilter.java
24-hour public links
Each link stores its own expiry and stops resolving after 24 hours.backend/…/publicsharing/service/PublicFileSharingService.java
Trash cleanup
A scheduled job at 02:00 removes items deleted more than 30 days ago.backend/…/file/service/AutoCleanupService.java
Storage
File contents in Amazon S3; accounts, shares, links and activity in PostgreSQL.backend/src/main/resources/application.properties
Next.js frontend
React and TypeScript with one API client that refreshes tokens on a 401.frontend/lib/api/client.ts
Tests and CI
Frontend tests run on every change, and the build fails if coverage drops..github/workflows/frontend.yml

Run it on your own server

You need Docker, a PostgreSQL database, an S3 bucket and an SMTP account for verification emails.

1

Get the code

$ git clone https://github.com/Daniel3886/CloudStore.git
$ cd CloudStore
2

Add your settings

Put your database, S3 and mail settings in backend/.env, and the API address in frontend/.env.local.

3

Start it

$ docker compose up -d
✓ backend   listening on :8080
✓ frontend  listening on :3000
